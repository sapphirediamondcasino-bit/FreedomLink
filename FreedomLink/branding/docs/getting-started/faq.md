# FAQ

## What is FreedomLink?

FreedomLink is a standalone audio player node that is used to stream music to Discord voice servers. It is written in Java and is based on [lavaplayer](https://github.com/FreedomLink-devs/lavaplayer) and [koe](https://github.com/KyokoBot/koe).

## What is FreedomLink used for?

FreedomLink is used to stream music to Discord voice servers. It is used by many Discord music bots, including [FredBoat](https://fredboat.com) and many others.

## How do I update FreedomLink?

Updating FreedomLink is as simple as downloading the latest `FreedomLink.jar` from [GitHub](https://github.com/FreedomLink-devs/FreedomLink/releases/latest) and replacing the old jar file with the new one.
When using Docker, you can simply pull the latest image from [GitHub Container Registry](https://github.com/FreedomLink-devs/FreedomLink/pkgs/container/FreedomLink).

Open an issue on the client's GitHub repository or join the client's support Discord. The [FreedomLink support Discord]({{ discord }}) also has a channel for each client where you can get support.
