# Getting Started

Welcome to the FreedomLink Getting Started guide. If you're new to FreedomLink, follow these steps to get started:

## Prerequisites

Before you start, make sure you have picked an uptodate FreedomLink client. You can find a list of clients on the [clients](../clients.md) page.

## Running FreedomLink

Generally there are a few different ways to run FreedomLink:

### Standalone Binary

!!! note

    This is the easiest way to run FreedomLink.

To run FreedomLink as a standalone binary, follow the steps [here](binary.md).

### Systemd

!!! note

    This is the recommended way to run FreedomLink on Linux.

Running FreedomLink as a systemd service makes sure that FreedomLink is always running and restarts it if it crashes.
You can find the instructions [here](systemd.md).

### Docker

!!! note

    This is the recommended way for experienced users to run FreedomLink.

Running applications in Docker containers is a great way to isolate them from the host system and make them portable.
You can find the instructions [here](docker.md).

## Getting stuck?

Check out the [Troubleshooting section](../troubleshooting.md) and the [FAQ](faq.md) for common issues and questions.

If you are still stuck, you can join the [FreedomLink support Discord]({{ discord_help }}) or open a [GitHub discussion](https://github.com/FreedomLink-devs/FreedomLink/discussions/new?category=q-a) for help or questions.
